# 分类标准文档 - 非天然氨基酸分类体系

## 一、分类体系概述

非天然氨基酸是指不属于标准20种蛋白质氨基酸的氨基酸类型。本分类标准涵盖7种主要的非天然氨基酸类型，并提供详细的识别和分类原则。

**注意**: 本文档是PDB-UAChecker v2.0系统分类功能的权威标准，系统的所有分类逻辑都严格遵循此标准。

## 二、七大分类类型

### 2.1 Alpha氨基酸（α-amino acid）
**结构定义**：氨基位于α-碳上，即羧基相邻的碳原子
- 通式：`NH2-CH(R)-COOH`
- 这是标准氨基酸的基本结构形式

### 2.2 Beta氨基酸（β-amino acid）
**结构定义**：氨基位于β-碳上，即距离羧基第二个碳原子
- 通式：`NH2-CH2-CH(R)-COOH`
- **重要**：α-碳上必须没有氨基，否则仍为α-氨基酸

### 2.3 Gamma氨基酸（γ-amino acid）
**结构定义**：氨基位于γ-碳上，即距离羧基第三个碳原子
- 通式：`NH2-CH2-CH2-CH(R)-COOH`
- **重要**：α-碳上必须没有氨基，否则仍为α-氨基酸

### 2.4 D型氨基酸
**结构定义**：手性中心为D构型（与天然L型相反）
- 费歇尔投影中，氨基在右侧
- 与L型氨基酸互为镜像异构体

### 2.5 N-甲基氨基酸
**结构定义**：主链骨架氨基上的一个氢被甲基取代
- Alpha型：`CH3-NH-CH(R)-COOH`
- Beta型：`CH3-NH-CH2-CH(R)-COOH`
- Gamma型：`CH3-NH-CH2-CH2-CH(R)-COOH`
- **注意**：侧链上的N-甲基化不属于此类

### 2.6 环状氨基酸（Cyclic amino acid）
**结构定义**：结构中含有一个或多个环状结构
- 可以是主链成环
- 可以是侧链含环
- 例如：脯氨酸及其衍生物

### 2.7 芳香族氨基酸（Aromatic amino acid）
**结构定义**：侧链（R基团）中包含芳香环结构
- 如苯环、吲哚环等共轭环系统
- 非天然芳香族氨基酸可能含有修饰的芳香环

## 三、详细判断标准

### 3.1 D/L型判断标准

#### 3.1.1 CIP规则判断
1. **确定α-碳手性中心**
2. **确定四个配体的优先级**（按原子序数）：
   - 优先级1：羧基（-COOH）
   - 优先级2：侧链（R）
   - 优先级3：氨基（-NH2）
   - 优先级4：氢（H）
3. **判断构型**：
   - 将优先级最低的基团（H）置于远离观察者
   - 观察1→2→3的排列顺序
   - 顺时针：R构型（对应D型氨基酸）
   - 逆时针：S构型（对应L型氨基酸）

#### 3.1.2 SMILES表示规则
- `C@H`：根据SMILES中原子排列，1-2-3顺时针为R(D)型
- `C@@H`：根据SMILES中原子排列，1-2-3顺时针为S(L)型
- **重要**：不能仅凭`@`或`@@`直接判断，必须结合原子排列顺序和CIP规则

#### 3.1.3 实例分析
```
SMILES: [NH3][C@H]([C](=O)=O)Cc1ccc(cc1)Cl
分析步骤：
1. 识别手性碳：[C@H]
2. 配体识别：NH3（氨基）、C(=O)=O（羧基）、Cc1ccc(cc1)Cl（侧链）、H（隐含）
3. CIP优先级：羧基(1) > 苯乙基(2) > 氨基(3) > 氢(4)
4. SMILES排列：NH3在左，羧基在括号内第一位，苯乙基第二位
5. 判断：1-2-3顺时针 → R(D)型
```

### 3.2 骨架类型判断标准

#### 3.2.1 判断原则
1. **从羧基碳开始计数**
2. **找到第一个连接氨基的碳原子**
3. **确定该碳在主链中的位置**

#### 3.2.2 关键区分
- **Alpha氨基酸**：氨基在α位，即使β或γ位有其他氮原子（属于侧链）
- **Beta氨基酸**：氨基在β位，且α位没有氨基
- **Gamma氨基酸**：氨基在γ位，且α位没有氨基

#### 3.2.3 错误示例
```
错误判断：DAB - [NH3]C[C](C@@H)([C](=O)=O)[NH3]
此结构α-碳上已有氨基，β位的氨基属于侧链
正确分类：Alpha氨基酸（带氨基侧链）
```

### 3.3 N-甲基化判断标准

#### 3.3.1 判断要点
- **必须是主链氨基的甲基化**
- **侧链氮的甲基化不计入此类**
- **主链氨基从NH2变为NH-CH3**

#### 3.3.2 SMILES特征
- 主链N-甲基：`CN` 开头或包含 `CNC`
- 侧链N-甲基：不影响分类

### 3.4 环状结构判断标准

#### 3.4.1 识别特征
- SMILES中的环标记：数字配对（如`C1...1`）
- 主链参与成环：如脯氨酸
- 侧链含环：如苯丙氨酸衍生物

### 3.5 芳香性判断标准

#### 3.5.1 识别特征
- SMILES中的芳香标记：小写字母（如`c1ccccc1`）
- 共轭π电子系统
- 平面性结构

## 四、文件格式中的标识

### 4.1 PDB文件
- **D型**：残基名前缀"D"（DAL, DGL, DVA等）
- **Beta**：可能含"B"或"3"（B3A, BAL等）
- **Gamma**：可能含"G"或"4"
- **N-甲基**：SAR（肌氨酸）、NME等
- **特殊记录**：HET、MODRES标签

### 4.2 SMILES格式
- **手性**：`@`和`@@`标记
- **环状**：数字配对
- **芳香**：小写字母
- **N-甲基**：`CN`而非`N`

### 4.3 其他格式
- **mmCIF**：_chem_comp类别标识
- **MOL2**：SUBSTRUCTURE记录
- **SDF**：特殊属性标签

## 五、分类优先级和流程

### 5.1 分类优先级
1. **骨架类型判断**（alpha/beta/gamma）
2. **手性判断**（D/L）
3. **N-甲基化判断**
4. **环状结构判断**
5. **芳香性判断**

### 5.2 复合分类
一个氨基酸可能同时属于多个类别，例如：
- "D-型 N-甲基 beta-氨基酸"
- "环状 芳香族 氨基酸"

### 5.3 判断流程
1. 首先确定主链骨架结构
2. 识别氨基位置确定alpha/beta/gamma
3. 分析手性中心确定D/L构型
4. 检查主链氨基甲基化
5. 识别环状和芳香结构
6. 综合所有特征给出完整分类

## 六、注意事项

### 6.1 常见错误
- 仅依靠`@`/`@@`判断D/L型
- 将侧链氮误判为主链特征
- 忽略α-碳已有氨基的情况
- 混淆侧链和主链的N-甲基化

### 6.2 特殊情况
- 某些氨基酸可能有多个手性中心
- 环状氨基酸可能限制某些构象
- 修饰的氨基酸可能有非标准命名

### 6.3 算法验证
- 使用多种方法交叉验证
- 参考晶体结构数据
- 检查二面角和原子距离
- 验证化学合理性
