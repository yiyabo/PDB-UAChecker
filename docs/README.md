# PDB-UAChecker v2.0 - 非天然氨基酸识别与分类系统

## 🎯 **系统概述**

PDB-UAChecker v2.0 是一个基于四重验证策略的非天然氨基酸识别与分类系统，集成了**搜索识别**和**智能分类**两大核心功能。

### 核心功能
- **🔍 搜索识别**：四重验证算法识别PDB文件中的非天然氨基酸
- **🧪 智能分类**：根据7种分类标准对氨基酸进行精确分类
- **📊 数据支持**：229种氨基酸数据库（20种标准 + 209种非天然）

## ⚡ **系统特点**

### 🔬 **四重验证搜索**
1. **分子式验证** - 化学身份基础验证
2. **原子组成验证** - 智能氢原子处理
3. **指纹相似性验证** - 重原子拓扑结构
4. **3D结构验证** - Kabsch算法最优叠合

### 🧪 **七维分类体系**
1. **骨架类型** - Alpha/Beta/Gamma氨基酸
2. **手性特征** - D/L型构型
3. **N-甲基化** - 主链氨基甲基化
4. **环状结构** - 环状氨基酸识别
5. **芳香性质** - 芳香族氨基酸
6. **复合分类** - 多特征组合分类
